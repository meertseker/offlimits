# Security policy

offlimits is a guardrail, so a bypass is a security bug.

## Reporting a bypass

- Sensitive: use GitHub private vulnerability reporting (Security tab, Report a vulnerability).
- Not sensitive: open an issue with the `bypass.md` template. It asks for command, role, expected, actual, Claude Code version and OS.

## What to expect

- Triage within 48 h.
- A fix, or a documented limit in `docs/limits.md`, within 7 days.
- No bounty.
